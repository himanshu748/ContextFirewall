# Getting help

- **Setup or usage questions:** check the [README](README.md) (MCP client setup, configuration
  reference, local run) and [`mcp/README.md`](mcp/README.md) first. If you are still stuck, open an
  [issue](https://github.com/himanshu748/ContextFirewall/issues/new/choose) and include what you
  tried, your MCP client, and the output you saw (with secrets redacted).
- **Bugs and feature ideas:** use the issue forms.
- **Security problems:** never post them publicly; follow [SECURITY.md](SECURITY.md).
- **Questions about Cognee itself:** ask in the [Cognee project](https://github.com/topoteretes/cognee).

The project is maintained by volunteers, so please be patient; we reply as soon as we can.
